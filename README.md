# ASLI

Chat con un'intelligenza artificiale che gira **interamente sul telefono**: il
modello sta sul dispositivo e la conversazione non passa mai dalla rete.
Niente account, niente raccolta dati.

**Questa è una beta**: serve a provare l'app e a raccogliere segnalazioni,
e può contenere difetti.

## Installazione

1. Scarica il file `.apk` dall'[ultima release](../../releases/latest).
2. Aprilo sul telefono: Android chiederà di consentire l'installazione da
   origini sconosciute per questa volta.
3. Al primo avvio l'app propone di scaricare il modello (circa 2,6 GB):
   conviene farlo sotto Wi-Fi.

## Requisiti

- Android 8.0 o successivo, processore a 64 bit (arm64)
- Spazio libero per il modello: circa 3 GB

## Privacy

Le conversazioni e le foto restano sul telefono, cifrate. La privacy policy
completa sarà pubblicata su
[questa pagina](https://andrea-salvadei.github.io/asli-beta/privacy/) insieme
alla prima release stabile.
